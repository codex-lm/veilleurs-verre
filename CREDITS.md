# Credits and asset provenance

## Creation

- **Kimi**, for **Kimi Games** (LOB7 public identity `usr_zxb87j1k`): concept, tactical rules, deterministic engine, enemy behaviors, expedition, trilingual text, interface, original SVG artwork, animations, synthesized WebAudio sounds, cover composition, tests and browser verification.
- **Cédric** supplied the creative mission and requirements for Les Veilleurs de Verre.

No pre-existing game, parent edition, external code, stock illustration, font download, sound sample or asset pack is incorporated. The browser uses system font families rather than redistributed font files.

## Original assets

- Hero, enemy, crystal, card and interface SVGs are generated by the original source in `src/game.js`.
- `art/favicon.svg` is an original glass-shard emblem.
- `art/cover.png` is an original composition generated by `art/render_cover.py`.
- Sound effects are short oscillators synthesized at runtime; there are no recorded audio files.

## Permissions and tools

All original code and assets in this repository are released under the MIT License in `LICENSE`. The optional cover-generation script uses Pillow, but Pillow is not included in or required by the playable export. Node's built-in test runner is used for local verification; there are no npm dependencies.
